# Embedded Projects

A collection of embedded development projects, experiments, and hardware/software prototypes.

This repository is intended as a central place for work across different boards, microcontrollers, and toolchains, including Arduino-, ESP-, and other embedded-focused setups. Each project can have its own source code, configuration, documentation, and assets while sharing the same top-level workspace.

## What you can expect

- Firmware and microcontroller projects
- Hardware-related notes and design assets
- Board-specific configuration files
- Project-level documentation and experiments
- A mix of quick prototypes and more complete builds

## Repository layout

Projects are organized in their own folders so they can stay self-contained. In general, each project may include:

- source files
- headers and libraries
- build or environment configuration
- assets such as schematics, diagrams, or exports
- project-specific README files

## Getting started

1. Open the project folder you want to work on.
2. Read the local project documentation first.
3. Install the required board support packages, SDKs, or tooling for that project.
4. Build, flash, and test using the workflow defined in the project itself.

## Notes

- Tooling may differ between projects.
- Hardware pin mappings, peripherals, and dependencies are project-specific.
- Some projects may be experimental and subject to change.
